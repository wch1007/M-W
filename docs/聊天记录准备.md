# 聊天记录准备

## 当前状态

2026-09-28：用户确认完整聊天记录在 iPhone；电脑上的完整性未知。已在电脑微信菜单看到“聊天记录管理”与“加载历史聊天记录”，尚未完成迁移、备份或可读导出。

## 先把完整对话迁移到电脑

1. iPhone 与电脑登录同一个微信账号，连接同一局域网。
2. iPhone 微信进入“我 → 设置 → 通用 → 聊天记录迁移与备份”。不同版本入口可能在“聊天”或“聊天记录管理”下，以实际界面为准。
3. 找到“迁移”及“迁移到电脑微信”一类选项后，选择当前这台电脑。
4. 只选择与张蔓的对话，选择全部时间范围；若出现内容类型选项，保留文字及需要的图片、视频、语音。
5. 按两端提示完成传输，保持微信打开。若界面与以上不同，记录实际选项后再决定，不用卸载或降级微信。

手机上的会话选择和开始迁移需要用户操作；助手可继续核对电脑端状态。

## 备份与可读导出分开验收

- **迁移**：让完整历史出现在电脑微信中，可以检索和核对。
- **备份**：保存微信用于恢复的数据。即使备份成功，也不能据此认定已取得可直接分析的 TXT、HTML 或 JSON。
- **可读导出**：取得包含日期、发送者、正文及附件对应关系的资料，才可用于整理故事。当前尚未确认这版微信有直接导出可读文件的入口，不能承诺一键导出。

如电脑“聊天记录管理”提供备份功能，可把备份目标设为本项目 `素材/聊天记录/微信备份/`。以界面实际支持为准，不移动微信正在使用的数据文件。

迁移完成后，再检查当前版本支持的本地导出方式。若需要额外工具，先核实工具来源、兼容性和处理范围；不把完整聊天上传到在线转换服务。人工精选截图可先用于文案准备，但不能冒充完整导出。
