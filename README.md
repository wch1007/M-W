## 开始放素材

照片可以直接放进 `素材/照片原图/`，保留原文件名；也可以按事件分文件夹，例如 `2026-05-31_第一次约会/`。暂时不知道日期的图片放 `素材/待整理/`。故事写在同文件夹的文字文件里即可，不需要先排版。

可直接填写 `素材/故事/故事填写模板.md` 与 `素材/日历/相聚日期.md`。已有的两件事已预填，其余保持空白，不编造经历。

| 位置 | 内容 |
| --- | --- |
| 素材/照片原图 | 原始照片，可保留拍摄信息 |
| 素材/视频原片 | 原始视频 |
| 素材/聊天记录/微信备份 | 微信自身生成的备份；不是可直接分析的文字稿 |
| 素材/聊天记录/可读导出 | 后续取得的 TXT、HTML、JSON 等可读记录 |
| 素材/聊天记录/精选截图 | 后续用于讲故事的对话片段 |
| 素材/故事 | 每张照片或每件事背后的故事 |
| 素材/日历 | 每次相聚的起止日期与地点 |
| 素材/参考 | 长图参考资料 |
| data/private | 从资料整理出的本地结构化数据 |
| docs | 准备步骤和网页需求 |

原始素材与真实故事数据已被 `.gitignore` 排除。Git 仓库先保存项目文档与代码；以后用于网页的精选照片、文案再单独整理。此规则只防止这些本地目录被默认提交，并不是网页访问控制。

## 网页维护

`dist/index.html` 是长页，`dist/style.css` 是手机与电脑排版，`dist/content.js` 是相聚日期和照片清单，`dist/app.js` 负责日历与照片展示。日历月份范围为 2026 年 5 月至 12 月，相聚日期段包含起止两天并按日期去重；线上认识与生日只显示纪念日标记。

补充相聚日期时，在 `dist/content.js` 的 `meetings` 中增加一项，字段为 `startDate`、`endDate`、`title`、`description`，可选 `chapter` 对应页面章节。这里的内容会随网页发布，并同步到公开 GitHub 仓库，只放拟展示内容。

精选网页照片另存到 `dist/photos/`，在 `photos` 中填写 `src`、`alt`、`caption`，有图片时照片章节自动显示。照片原图仍保留在本地 `素材/照片原图/`。
