## 开始放素材

照片可以直接放进 `素材/照片原图/`，保留原文件名；也可以按事件分文件夹，例如 `2026-05-31_第一次约会/`。暂时不知道日期的图片放 `素材/待整理/`。故事写在同文件夹的文字文件里即可，不需要先排版。

可直接填写 `素材/故事/故事填写模板.md` 与 `素材/日历/相聚日期.md`。已录入用户提供的 15 段经历，其余继续按真实资料补充。

## 网页维护

`dist/index.html` 是长页，`dist/style.css` 是手机与电脑排版，`dist/content.js` 是故事和照片清单，`dist/app.js` 负责故事、日历、计时与照片展示，`dist/dates.js` 负责日期计算。日历范围为 2026 年 5 月至 12 月，相聚日期段包含起止两天并按日期去重。5 月 18 日、8 月 19 日异地七夕、9 月 9 日赴新疆与生日只显示纪念日标记。

`dist/memories.js` 仅保存拟公开的精选原话及编辑导语；来源行号对照在被忽略的 `data/private/chat-excerpt-provenance.json`。月份使用原生 `details/summary` 默认收起，日历或哈希深链会打开目标所在月份。`dist/places.js` 保存城市级线索和地图计算：当天事实与历史线索分开标注，数据之外的未来日期不推断位置，同处新疆不视作相聚。仅陆地轮廓的本地 SVG 来源为 Natural Earth 公共领域数据；没有地图服务密钥、在线瓦片请求或定位权限。

补充故事时，在 `dist/content.js` 的 `events` 中增加一项，字段为稳定的 `id`、`startDate`、`endDate`、`title`、`description`、`tag` 和 `kind`。实际相聚使用 `meeting`，其他纪念事件使用 `milestone`。这里的内容会随网页发布，并同步到公开 GitHub 仓库，只放拟展示内容。

计时从北京时间 2026-05-18 00:00:00 起按已过去的时间递增，每秒刷新；2026-09-30 零点为 135 天。日期、摘录结构与地图边界验证运行 `node --test tests/*.test.cjs`。

精选网页照片另存到 `dist/photos/`，在 `photos` 中填写 `src`、`alt`、`caption`，有图片时照片章节自动显示。照片原图仍保留在本地 `素材/照片原图/`。

修改 `dist/index.html` 后运行 `node scripts/prepare-pages.cjs` 同步根入口，再提交并推送到 `main`。`node scripts/prepare-pages.cjs --check` 检查入口是否同步。脚本与样式继续由 `dist/` 提供，图片路径相对于 `dist/` 解析。当前正式发布使用 GitHub Pages，不再依赖 Sites；旧的 `.openai/hosting.json` 仅保留历史关联。
